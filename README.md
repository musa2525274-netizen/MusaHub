# Musa Hub

SwiftUI tabanlı çok amaçlı iOS uygulaması başlangıç projesi.

## İlk modüller

- AI
- Tools
- Notes
- Tasks
- Files
- Developer
- Study
- Screen Recorder

## Ekran kaydı

Başlangıç sürümünde ReplayKit ile uygulama içi ekran kaydı altyapısı eklenmiştir.

Önemli: iOS'un tamamını (Ana Ekran dahil) kaydetmek için normal `RPScreenRecorder` yaklaşımından farklı olarak ReplayKit Broadcast Upload Extension ve uygun kullanıcı akışı gerekir. Bu starter, uygulama içi kayıt altyapısını kurar.

## Kurulum

1. Xcode'da yeni bir iOS App projesi aç.
2. SwiftUI + Swift kullan.
3. Bu `.swift` dosyalarını projeye ekle.
4. Deployment Target'ı cihazına uygun iOS sürümüne ayarla.
5. Gerçek cihazda çalıştır.

Sonraki aşamada gerçek modüller tek tek eklenebilir.
